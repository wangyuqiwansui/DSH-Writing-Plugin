# 浮动 AI 对话

工作台右上角的 **AI 对话** 按钮默认收起。点击后在工具栏下方展开浮动对话框，布局参考 DSH `0.2.1-rc.2` 原有消息区和底部输入框，采用本工程黑白灰样式。对话作为独立模块管理状态，不占用小说、世界观或质量检测的业务状态。

## 使用

- 使用工作台顶部统一选择的模型和推理等级；发送时固定本次配置，之后切换模型影响下一次请求。
- Enter 发送，Shift + Enter 换行，中文输入法选词不触发发送。回复逐段显示，可随时停止。
- 支持复制、重新生成最后一条回复、新对话、放大/还原、收起；Escape 收起并把焦点还给入口按钮。生成期间可收起并继续浏览工作台。
- 默认固定在右上角。点击标题栏的图钉解锁后，可拖动标题栏移动；标题区获得键盘焦点后也能用方向键调整（Shift 加速）。再次点击图钉固定回右上角。拖动限于工作区，放大或窗口缩小时保持可见；拖动中按 Escape 或触发 pointercancel 恢复原位置。
- 切换页面或收起保留对话和未发送草稿；重新加载、卸载工作台会清空。本模块当前不保存聊天历史到数据库。
- 收起保留当前位置和固定状态；重新加载后恢复默认固定位置。
- 未配置模型、断线、超时或模型失败时给出提示，保留已收到的文字；重试由用户点击，不自动重复调用。恢复连接后可继续发送。

助手仅接收用户在对话里提供的内容，不自动附加小说、世界观、Wiki 或作者人格，不执行工具或改写业务数据。对话建议需作者自行应用。

## 装配与边界

根插件默认装配 `src/modules/chat/host.ts`；配置 `chat: false` 可停用服务，入口仍可展开查看未连接提示。`writingChat` 必需依赖 `typert` 和 `writingModels`；依赖消失时终止活动请求，恢复后重建服务。前端通过独立远程接口连接，业务模块无须依赖对话模块。

默认配置如下，修改根配置时保留同一行已有的 `databasePath`、`defaultModel` 等字段：

```yaml
chat:
  timeoutMs: 180000
  maxTokens: 8192
```

`timeoutMs` 范围 1000–300000；`maxTokens` 范围 256–32768。使用现有 DSH `writingModels.prepare()` 和公开 LLM SDK；不新增供应商或密钥配置。原生聊天组件绑定 DSH 会话服务且没有独立嵌入入口，本模块参考其布局，未导入宿主私有 UI 实现。

| 层 | 职责、合同和完成条件 |
| --- | --- |
| `contracts.ts` | 严格校验请求、消息顺序、模型来源与流事件；RPC `writingChat.stream` 只接受所有者身份。 |
| `service.ts` | 固定一次模型调用，管理超时、并发和取消；发出 `start → thinking?/delta* → finish`，缺少完成标记或空回复判失败。 |
| `host.ts` | 将公开 DSH LLM 类型转换为模块事件；历史助手消息通过 `createAssistantMessage` 创建有效身份与来源；不向客户端传递模型内部推理文本。 |
| `client/controller.ts` | 管理本次会话、草稿和请求状态；取消立即生效、迟到响应隔离；完整/截断回复参与后续上下文，失败/取消回复不混入。 |
| `client/FloatingChat.tsx` | 渲染和键盘交互；消息与安全 Markdown 组件复用，UI 不操作模型服务或数据库。 |
| `client/useChatPlacement.ts` | 独立管理固定状态、拖动坐标、指针捕获和尺寸适配；不读取会话内容或调用 Host，关闭/卸载清理观察器及事件。 |

一条输入最多 12000 个 UTF-16 单元，上下文最多 80000、请求最多 41 条消息（20 组历史问答加当前问题），回复最多 64000。超限提示开启新对话或缩短输入，不静默删减上下文。同一前端同时只发起一条请求，服务最多允许两条并行请求；同一活动请求标识拒绝重复执行。停止向供应商传播 AbortSignal，是否终止远端计费取决于适配器与供应商；此实现不声称远端执行回滚。

## 验证

根目录 `tests/` 仅留本地，不随 Git 分发。以下业务回归需要具备本地测试文件；公开 `npm test` 仅构建并运行独立回测自检。

- `npm run test:local`：构建、领域/控制器、相邻模块回归。
- `node --test tests/chat.test.mjs`：边界、流式事件、超时、取消、迟到消息、重试、公开 SDK 与真实 Loader 依赖卸载/恢复。
- `node scripts/check-chat-host.mjs`：本机已安装 DSH 的隔离 Host + Web、受控模型适配器；支持 `DSH_INSTALL_PATH`、`PLAYWRIGHT_MODULE`、`CHROMIUM_PATH`、`OUTPUT_DIR` 环境变量。
