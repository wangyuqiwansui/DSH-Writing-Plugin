# 作者人格模块

目录标识：`author-persona`。状态：目录占位，尚无运行实现。

负责作者的创作立场、叙事习惯、表达偏好等写作人格资料及版本。它是可供作品选择的创作资料，不是小说内的人物角色。

计划子目录：`host/`、`client/`、`contracts/`、`application/`、`domain/`、`repository/`。小说通过公开服务读取与引用人格版本，不复制维护第二套人格资料库。

资料来源、编辑字段、提取流程及模型调用将在功能设计阶段处理，本轮不实现。

目录基线见 [目录结构规划](../../../目录结构规划.md)。功能和技术细节后续归档到 `docs/modules/author-persona/`。
