# 作者人格模块

目录标识：`author-persona`。状态：人工配置、持久化版本与工作台入口已实现（2026-10-26）。

负责作者的创作立场、叙事习惯、表达偏好等写作人格资料及版本。它是可供作品选择的创作资料，不是小说内的人物角色。

`contracts/` 定义公开接口；`domain/` 处理解析、校验和表达编译；`application/` 拥有版本与发布规则；`host/` 装配服务；`client/` 拥有编辑状态和界面。持久化复用中间件受限端口，不设置私有 repository 或数据库。

小说通过公开 `PersonaProjection` 接收指定已发布版本，不导入人格领域实现，不另建人格资料库。模型提炼、来源审核、能力选择和文学实测未接入；所有版本如实记录 `not_run`。

使用方式、接口与验证入口见[作者人格模块](../../../docs/modules/author-persona/README.md)。
