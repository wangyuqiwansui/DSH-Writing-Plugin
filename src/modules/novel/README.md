# 小说模块

目录标识：`novel`。状态：目录占位，尚无运行实现。

负责小说身份、基础信息、创作内容及世界观、作者人格的引用。首期一部小说对应一个写作项目；主工作台只持有当前选择的小说引用，不维护第二套项目记录。

计划子目录：`host/`、`client/`、`contracts/`、`application/`、`domain/`、`repository/`。跨模块协作放在应用层，经公开服务读写，不直接查询其他模块私有仓储。

小说列表不要求已选择作品；作品详情及相关操作必须有明确小说身份。章节、人物、生成流程等细节留待功能设计。

目录基线见 [目录结构规划](../../../目录结构规划.md)。功能和技术细节后续归档到 `docs/modules/novel/`。
