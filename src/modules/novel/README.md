# 小说模块

目录标识：`novel`。状态：七入口的内存版手动创作工作区已实现；数据库和自动生成流程尚未接入。

负责小说身份、基础信息、创作内容及世界观、作者人格的引用。首期一部小说对应一个写作项目；主工作台只持有当前选择的小说引用，不维护第二套项目记录。

当前目录：`contracts/` 定义版本、来源、确认与命令；`domain/` 定义分层字段和结构检查；`application/service.ts` 拥有会话数据与领域命令；`client/` 拥有页面和未保存编辑缓冲。写入没有独立 Host、repository、SQL、localStorage 或 IndexedDB 依赖；材料查询通过世界观公开合同读取已绑定精确来源，查询控制器仅持有临时结果。后续持久化统一接入 `writingStorage`，不创建模块私有数据库。

七入口为资产配置、小说设定、总纲（含分卷）、单元规划、章节规划、正文、独立角色库。逐章剧情只归章节规划，正文直接引用其精确确认版本；不增加旧章纲门槛。详情、角色和所有写命令按小说身份隔离。

实施范围、接口、验证与当前能力边界见 [小说模块说明](../../../docs/modules/novel/README.md)。
