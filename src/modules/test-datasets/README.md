# 功能测试集导出

公开入口为 `index.ts` 的纯数据构造函数及 `client.tsx` 的编辑/下载组件。输入是所属功能页面已读取的资料快照，输出为 `backtest-dataset-v1` JSON 文件。

本模块不接 Remote、数据库、模型或系统配置端口；不运行回测，也不导入回测评分器。知识库与世界观页面通过组件组合提供入口，各自业务控制器不持有测试执行方法。

测试集用例由用户编辑，原文与片段元信息由文件快照带出。生成模板后需要核对人工标准证据、独立 dev/test 分组，勾选审阅仅表示作者声明，不自动证明数据质量。

执行、指标和报告在工程根目录 [backtesting/](../../../backtesting/README.md) 单独维护；输出报告位于 Git 忽略的 `backtest-reports/`。
