# 世界观模块

目录标识：`worldbuilding`。状态：目录占位，尚无运行实现。

负责世界观资料及其身份、版本和业务规则。对外提供资料选择与精确版本读取；小说通过引用使用世界观，不能直接写其私有仓储。

计划子目录：`host/`、`client/`、`contracts/`、`application/`、`domain/`、`repository/`。模块内容不是独立安装包；内部处理节点也不等于一套独立数据库。

现有 `world` 占位标识将在导航整理阶段映射到 `worldbuilding`，本轮未变更运行入口。

目录基线见 [目录结构规划](../../../目录结构规划.md)。功能和技术细节后续归档到 `docs/modules/worldbuilding/`。
